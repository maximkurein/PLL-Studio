## [0.1.1] - 2026-11-08

### Fixed
- Карточки RO/sticky и соответствующие биты карты регистров показывают значения последнего readback (включая DEV_ID/REV_ID), а до чтения — неизвестное значение вместо нулей из конфигурации для записи.
- Уточнён аппаратный путь readback EVB: R2 в линии MUX_OUT → MISO помечен NP. Для штатного USB добавлена диагностика недостоверного R7 из сплошных 0/1; ACK SC18IS602 не считается подтверждением записи PLL.
- Частичная запись в устройство больше не подменяет неизвестные регистры значениями по умолчанию; ошибка обмена сбрасывает кэш и readback. При переключении с симулятора убраны устаревшие показания захвата.
- Параметры EVB сверены с материалами производителя: внешнее питание 4 В на LDO_PWR, корпус 32-VFQFN 5×5 мм, аппаратная доработка для опоры J1, назначение JP1/JP2/JP3 и мост FTDI → I²C → SC18IS602 → SPI.
- Новые настройки используют RCP = 4.7 кОм и петлевой фильтр по схеме Rev A от 14.05.2015; ранее сохранённые настройки не перезаписываются.
- Отметки полюсов фильтра третьего порядка учитывают взаимное влияние RC-ветвей по формулам калькулятора производителя.

### Added
- Экран «О программе»: версия и дата выпуска, разработчик Kurein M N, лицензия, режим запуска и подключение, ссылки GitHub/Forgejo с копированием git clone. Доступен из меню, кнопки ℹ, подписи версии и по ⌘/Ctrl+0.
- Сведения о приложении синхронизируются из `config/version.json` в модуль `pll-core::about`, Cargo/npm и метаданные установщиков. `status` проверяет версию и идентичность; добавлены регрессионные проверки синхронизации и версии ядра. Версия поднята штатным инструментом до 0.1.1.
- Через Tauri проверена перестройка 2480→2490→2500 МГц по штатному USB с чтением новых делителей, DIG_LOCK=1, BAND_SEL_DONE=1 и SPI_ERROR=0; исходная конфигурация восстановлена и прочитана обратно.
- Штатный USB проверен через нативный desktop-интерфейс Tauri на macOS: подключение, запись и чтение R0–R7 с совпадением конфигурации, DEV_ID=6, REV_ID=1, SPI_ERROR=0; оба RF-выхода отключены и подтверждены readback.
- Аппаратный readback через штатный USB подтверждён 08.11.2026 с замкнутым R2: R0–R7 совпадают, INT=100→101→100 прочитан обратно, DEV_ID=6, REV_ID=1, SPI_ERROR=0. Дополнительная пауза/очистка INT обычному транспорту не потребовалась; добавлен расширенный диагностический пример `evb_usb_read_audit`.
- Аппаратная проверка 08.11.2026: пользователь подтвердил три мигания LD при записи R5 через штатный USB. Отсутствие R2 на проверенной плате подтверждено пользователем; чтение и остальные регистры этим тестом не проверены.
- Визуальная проверка SPI-записи по LD: пример `evb_usb_ld_test --blink` трижды переключает только R5 и возвращает Digital Lock Detect.
- Аппаратные диагностические примеры: запись/чтение R0–R7 с отключёнными RF-выходами, контроль DEV_ID и INT, проверка GPIO SC18IS602 и постоянных уровней MUX_OUT.
- Диагностический пример `evb_usb_probe`: проверка штатного моста без записи регистров PLL; ошибка SCL теперь содержит фактический байт GPIO.
- Экспериментальный штатный USB EVB: FT2232 A → I²C 0x28 → SC18IS602 SS0, запись/чтение без внешнего SPI-моста; отдельный выбор устройства, таймауты, NACK/clock stretching, блокировка повторного обмена после ошибки. Подключение не записывает PLL и отключает авто-запись; CE/MUTE/LD через USB недоступны.
- Регрессионные проверки полюсов по Excel-калькулятору и расчёта частот по шести конфигурациям Timing Commander; справка об источниках и различиях между ними.
- Локальная папка `info/` исключена из Git, материалы производителя остаются на диске.

## [0.1.0] - 2026-11-07

Первая версия: лаборатория RF-синтезатора 8V97051 и платы 8V9705x EVB для macOS и Windows.

### Added
- **Модель кристалла на Rust (`pll-core`).** Полная карта регистров R0–R7 с точными позициями битов по даташиту, описаниями полей, признаками двойной буферизации и только-чтения; проверка ограничений даташита (диапазоны ГУН, fPFD, такт калибровки, окно Lock Detect, режимы MOD/FRAC) с пояснениями на русском.
- **Планировщик частоты**: точный рациональный поиск ×2 / R / ÷2 / INT / FRAC / MOD (12 и 16 бит) / M0 с оценкой шума в полосе и ближних спуров каждого варианта; быстрая перестройка ±шаг.
- **Петля ФАПЧ**: расчёт пассивного фильтра 2-го/3-го порядка по методике даташита с округлением до E12/E24, диаграмма Боде, замкнутая петля, нелинейный переходный процесс (насыщение PFD, проскальзывание циклов, Lock Detect).
- **Фазовый шум**: вклад опоры (TCXO), PFD/накачки, ΣΔ, ГУН и выходного пола; RMS-джиттер; оценка спуров PFD, integer boundary и дробных; виртуальный анализатор спектра.
- **Симулятор 8V97051**: двойная буферизация, калибровка ГУН с таймингом и ошибкой при неверном такте, захват петли, чтение регистров через MUX_OUT, sticky-флаги R7, температурный дрейф, CE/MUTE, внедрение SPI-ошибки.
- **Подключение железа**: последовательный SPI-мост (текстовый протокол `PLLBRIDGE`) и прошивка для 3.3-вольтовых плат Arduino/Nucleo/RP2040; сканер USB с подсказками по известным мостам (FTDI, Cypress, Silicon Labs, MCP2210…).
- **Интерфейс** (React 19 + Tailwind 4, тёмная/светлая тема): интерактивная анимированная архитектура кристалла и платы, вид платы EVB с чек-листом первого запуска, карта регистров по битам, планировщик, петля, шум и спектр, лаборатория (свип, прыжки частоты, температура, фаза, отказы), подключение, «Академия» из 11 уроков, SPI-консоль с расшифровкой полей.
- **Режимы запуска**: desktop (Tauri 2, macOS и Windows) и веб/удалённая лаборатория (`pll-server`, axum) с одним и тем же RPC.
- **Документация с иллюстрациями**: README со скриншотами всех экранов, схемы «Как работает синтезатор», «Архитектура программы» и «Подключение платы» (`docs/images`).
- **Инфраструктура**: единый источник версии `config/version.json` и `tools/update_version.py`; скрипты сборки `build_macos.py`, `build_windows.ps1`/`.bat`; `Makefile`; GitHub Actions (CI и релиз по тегу); шаблоны issue/PR.
