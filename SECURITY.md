# Безопасность

## Поддерживаемые версии

Исправления выпускаются для последней версии (см. `config/version.json` и [CHANGELOG.md](CHANGELOG.md)).

## Как сообщить об уязвимости

Не открывайте публичный issue для проблем безопасности. Используйте приватное сообщение об уязвимости в GitHub (Security → Report a vulnerability) или напишите владельцу репозитория напрямую.

Укажите:

- версию PLL Studio и ОС;
- режим (desktop или `pll-server`);
- что может сделать атакующий;
- шаги воспроизведения или минимальный пример.

## Что хранит и куда обращается приложение

- **Desktop-режим** не открывает сетевых портов. Состояние (регистры, настройки фильтра, опоры) хранится в JSON в папке настроек приложения: `~/Library/Application Support/com.pllstudio.desktop/` (macOS), `%APPDATA%\com.pllstudio.desktop\` (Windows). Паролей и ключей нет.
- **`pll-server`** по умолчанию слушает только `127.0.0.1:7878`. Аутентификации нет: любой, кто может открыть адрес, может записывать регистры подключённой платы. Запуская с `--host 0.0.0.0`, ограничьте доступ (файрвол, VPN, SSH-туннель). CORS разрешён для удобства разработки.
- Приложение не отправляет телеметрию и не обращается к интернету. Исключение — установщик Windows может скачать WebView2, если его нет в системе.
- Последовательный порт и USB открываются только по явному действию пользователя. Сканер USB читает лишь дескрипторы устройств (VID, PID, строки производителя).

## Безопасность железа

Неверная конфигурация не повредит 8V97051, но неправильное подключение может:

- логика SPI-моста — **только 3.3 В** (входы кристалла 1.8 В, толерантны к 3.3 В); 5-вольтовые Arduino без преобразователя уровней не подключайте;
- не подавайте постоянное напряжение на выходы RF_OUT (открытый сток);
- до +7 dBm на выходе — защищайте вход анализатора спектра аттенюатором;
- перед подключением внешнего моста изолируйте штатный USB-контроллер EVB от линий SPI.
